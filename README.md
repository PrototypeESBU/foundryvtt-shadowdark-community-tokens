# Shadowdark RPG Community Tokens
A project by Delgore for use with Foundry VTT and other virtual tabletops

This is a collection of black and white monster tokens made with a mixture of hand drawn and AI generated art for use with Shadowdark RPG. While this module is specifically designed for Foundry and Shadowdark, the tokens and artwork can be downloaded for use in any VTT game. This is a community effort that includes artwork from many contributors and artists. All artwork is used with the given consent of the creators.  Artwork for the Stingbat was created by @WatcherDM on Discord, and the Aboleth was created by @JeriHoneywell and may only be redistributed with their permission.   All other artwork is AI generatated and can be freely used.   Any resemblance to existing artwork was not intended and will be removed/replaced as soon as we are made aware.

Automated token mappings is supported for the following systems:
- Shadowdark RPG System
- Shadowdark Community Content Module

## Includes
- Replacement portrait and token art for all 243 core rule book monsters
- Replacement portrait and token art for all 250 monsters by Tom Philips in Community Content
